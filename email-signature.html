Add it to Outlook

  1. Open Outlook on the web (outlook.office.com) and click the gear icon (Settings).
  2. Go to Account → Signatures.
  3. Name it "Hello Rivers" and paste into the signature box (Cmd+V).
  4. Set it as the default for new messages and replies, then click Save.

On the Outlook Mac app: Outlook → Settings → Signatures → + → paste.
